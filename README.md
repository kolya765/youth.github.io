# Юность — адаптивная вёрстка

41 страница утверждённого макета + `pages.html` для просмотра всех страниц.
Только HTML5 и CSS3. Без JavaScript, сборщика, библиотек и серверной части.
Шрифт, логотип, иллюстрации и фотографии находятся локально в `assets`.

## Как открыть

1. Полностью распакуйте архив.
2. Откройте `index.html` браузером — это главная страница сайта.
3. Откройте `pages.html`, чтобы перейти к любому кабинету или экрану.

Это веб-страницы, а не плагин Figma. Переименовывать файлы не нужно.
В кабинеты для проверки переходят через `pages.html`. Страница входа не
выполняет авторизацию и не предоставляет доступ к реальным данным.

При необходимости локального HTTP-сервера (если установлен Python):

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/. Команду выполняйте в распакованной папке.

## Что реализовано

- Главная страница: официальный логотип, шапка, меню, контент и подвал.
- Открытые страницы направлений, программы, центра, педагогов, новостей,
  документов, галереи, контактов, входа, регистрации и порядка записи.
- Кабинеты родителя, педагога и администратора.
- Общие стили и компоненты: кнопки, поля, карточки, таблицы, подсказки.
- Адаптивная раскладка от 320 px, промежуточные размеры и десктоп 1440 px.
- Бургер на `<details>` / `<summary>`: открывается и закрывается без JavaScript,
  доступен с клавиатуры. На широком экране кабинета — боковое меню.
- Рабочие ссылки между страницами, контактные и официальные внешние ссылки.
- Настоящие HTML-поля, выбор файлов и стандартные элементы формы.

## Пустые данные и границы этапа

Учебные ФИО, контакты пользователей, заявления, учащиеся, группы, расписание,
достижения и уведомления не включены. Каталоги программ, педагогов, новостей,
документов и альбомов также пусты. Сохранены названия разделов и полей,
статическая информация о центре, четыре адреса и декоративные изображения.
Детальные страницы показывают состояние «запись не выбрана».

Кнопки сохранения, входа, регистрации, фильтрации, отправки и выгрузки
не выполняют действий. Серверные кнопки отключены; фильтры можно выбрать,
но результаты не меняются. Ввод в поля возможен, данные не сохраняются.
Файлы в поле загрузки выбираются только локально, никуда не отправляются.
Нулевые счётчики показывают пустое состояние, это не статистика учреждения.

Это этап вёрстки. Нет имитации успешной авторизации или сохранения, БД,
запросов к API и реализации ролевой защиты. Правила из утверждённых
документов отображены в подписях и формах; серверные проверки будут
реализованы при подключении приложения. Внутреннее обращение не заменяет
официальную запись через uslugi.mosreg.ru или МФЦ.

## Как редактировать

Структура и тексты — в соответствующем `.html` файле. Общие цвета, размеры,
сетка и адаптивные правила — в `assets/styles.css`. Классы `panel`, `button`,
`field`, `hero`, `dashboard-grid` используются повторно на всех страницах.
В конце CSS находятся медиазапросы. Общие шапки и меню пока продублированы
в HTML, поскольку на этом этапе нет шаблонизатора или JavaScript.
Фотографии и SVG — отдельные файлы, вёрстка не собрана из скриншотов.

Для сдачи создайте репозиторий на GitHub и загрузите СОДЕРЖИМОЕ этой папки:

## Проверка

Все 42 HTML проверены в Chromium на ширинах 320, 393, 768 и 1440 px:
168 комбинаций страницы и ширины. Проверены ссылки и ресурсы, отсутствие
горизонтального переполнения, загрузка изображений, меню, подписи полей,
ввод в регистрационную форму и отсутствие отправки пароля при Enter.
Результаты — `validation.json`. Скриншоты примеров — в `preview`.
Проверка выполнена через локальный HTTP-сервер. Другие браузеры отдельно
не проверялись. Утверждённая документация не изменялась.
